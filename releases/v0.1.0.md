首个发布版本。PoemReader 是一个 Windows 上的极简文档查看与打印工具，用 Rust + GPUI 自绘界面，一个 exe 即可运行。

## 支持的格式

- **纯文本**（UTF-8 含 BOM / GB18030）：不限大小，按窗口宽度折行，上百 MB 也能秒开
- **PDF**：按页栅格化显示，保留字体、表格、矢量图与内嵌图片；缩放 75%–200%
- **Markdown**：标题、列表、引用、GFM 表格、围栏代码块、脚注、本地图片，不显示标记符号
- **Word**（`.docx`）与旧版 **Word 97-2003**（`.doc`）：段落样式、字符格式、列表、表格与合并单元格、内嵌图片
- **Excel**（`.xlsx`）与旧版 **Excel 97 / BIFF8**（`.xls`）：字体、填充、边框、对齐与自动换行、合并单元格、多工作表、数字格式
- **图片**：JPEG / PNG / BMP / WebP / ICO / GIF（含动画）/ SVG（含 `.svgz`）

## 这一版的重点

- 打印与打印预览使用同一套排版代码，预览里的分页位置就是打印出来的样子
- 预览按需渲染：只有看得见的页才画，几百页的长文档也能立刻显示第一页
- 打开文件、折行、页面渲染都在后台线程，界面不会卡住
- 划选复制：纯文本按字符、Markdown / Word 按段落、Excel 按单元格矩形
- 可注册为这些格式的「打开方式」候选

## 安装

1. 解压 `PoemReader-0.1.0-win64.zip`
2. 双击 `install.cmd`

安装脚本免管理员权限，会把程序复制到 `%LOCALAPPDATA%\Programs\PoemReader`，
并在「设置 → 应用」里登记（可从那里卸载）。不想安装的话，直接运行解压出来的 `PoemReader.exe` 也能用。

## 系统要求

- Windows 10 / 11 x64
- 需要 Microsoft Visual C++ 运行库（绝大多数系统已自带）

## 已知限制

- 加密 / 需要密码的 PDF 不支持
- 旧版 `.doc` 的图片、页眉页脚、脚注与单元格合并暂不呈现
- 加密的 `.xls` 与 BIFF5 及更早版本不支持
