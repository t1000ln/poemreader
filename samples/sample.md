# PoemReader Markdown 示例

这是一份用于验证 **Markdown 显示与打印** 的示例文档，包含标题、强调、
列表、表格、代码块、引用与图片。

## 行内格式

支持 **加粗**、*斜体*、***加粗斜体***、~~删除线~~、`行内代码`，
以及 [链接文字](https://gpui-kit.com)。

## 列表

- 无序列表项
- 第二项
  - 嵌套的子项
  - 另一个子项
- 第三项

1. 有序列表第一项
2. 有序列表第二项
3. 有序列表第三项

- [x] 已完成的任务
- [ ] 未完成的任务

## 引用

> 阅读是一场安静的旅行。
>
> 排版应当让文字自己说话。

## 代码

```rust
fn main() {
    let title = "PoemReader";
    println!("Hello, {title}!");
}
```

## 表格

| 格式 | 扩展名 | 打印 |
| :--- | :--- | ---: |
| 纯文本 | `.txt` | 支持 |
| Markdown | `.md` | 支持 |
| Word | `.docx` | 支持 |
| Excel | `.xlsx` | 支持 |

## 说明

- 标题会加粗并放大显示
- 表格保留表头底色与边框
- 代码使用等宽字体并带浅色底纹
- 相对路径的图片会随文档一起显示并打印
